BATT WILLIAMS / $KATTBATT WEBSITE
=================================
Upload EVERYTHING in this folder (keep the folder structure) to your web host.

  index.html          - homepage
  games/flappy.html   - Flappy KATTBATT
  games/baseball.html - Batt Williams Baseball
  assets/             - images

Works on Cloudflare Pages, Netlify, GitHub Pages, or any regular host.

TO EDIT:
- Links, contract address, YouTube video: open index.html, scroll to the bottom,
  edit the CONFIG block.
- Hero background: add assets/bg-batt-williams.jpg (optional).
- Domain is set to kattbatt.com (CNAME file included for GitHub Pages).
