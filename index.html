About

Batt Williams is a community meme-coin project on Solana built around KattBatt, a bat-winged baseball bat character. The project runs a looping video channel on YouTube and two free browser games — Flappy KATTBATT and Batt Williams Baseball — that anyone can play in a browser with no sign-up and no wallet connection.

The $KATTBATT token trades on pump.fun. The only official contract address is the one shown on this page; it is also linked from the project's X and YouTube accounts. Anything listing a different address is not this project.
